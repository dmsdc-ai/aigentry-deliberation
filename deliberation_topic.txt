User Suggestion: Integrate `aigentry-brain`'s CMP (Context Management Protocol) with `aigentry-deliberation` to enable advanced cross-machine context injection and result synchronization.

Current State: 
- `aigentry-deliberation` supports cross-machine context injection via Tailscale using `deliberation_inject_context` (taking simple text).
- `aigentry-brain` supports CMP via `brain_session_export` and `brain_session_import`.

Proposed Features:
1. Enhance `deliberation_inject_context` (or add a new tool) to accept a `cmp_payload` (JSON array of memory entries) and inject them structurally into the deliberation session.
2. Add a `deliberation_export_cmp` tool to convert a completed deliberation session (or its synthesis) into a CMP package that can be imported back into the user's `aigentry-brain`.

Objective: Evaluate this proposal. Is this the right architectural direction? Are there edge cases or better approaches? How should the MCP tools be structured to keep the interface clean while maximizing the synergy between the two systems?
